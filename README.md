# astrbot_plugin_char_mixer

让你的 AstrBot 角色拥有「拍照」能力 —— 基于 gpt-image-2 的二次元角色自拍 & 合影插件。

角色可以像真人一样随手自拍、和用户合影，二次元角色自然融入真实世界背景。

## 效果

- 🤳 **角色自拍** —— 角色在真实场景中拍照，保持二次元画风不写实化
- 📸 **合影/入镜** —— 用户发一张照片，角色出现在照片里，和用户合影或融入场景
- 🎭 **姿势表情自然** —— 比心、歪头、吐舌头、wink，不是呆板站姿
- 🌆 **真实背景** —— 涩谷街头、教室走廊、海边夕阳，有地点感和时间感

## 安装

1. 下载本仓库 zip 或 clone 到 AstrBot 插件目录：
   ```
   {AstrBot数据目录}/data/plugins/astrbot_plugin_char_mixer/
   ```
2. 重启 AstrBot后端

## 配置

在 AstrBot 管理面板中配置插件参数：

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `openai_api_key` | API Key（支持兼容服务） | — |
| `openai_base_url` | API 地址（填到 /v1） | `https://api.openai.com/v1` |
| `image_model` | 图片模型 | `gpt-image-2` |
| `image_quality` | 图片质量 (low/medium/high) | `high` |
| `char_reference_path` | 默认三视图路径 | — |
| `char_reference_map` | 平台 → 三视图映射（template_list） | — |
## 工作原理

插件注册了两个 LLM Tool：

- **`generate_character_selfie`** —— 角色自拍。LLM 根据对话上下文自主决定场景、服装、姿势和横竖屏方向。
- **`generate_photo_with_user`** —— 合影/入镜。用户发送照片后，LLM 决定如何将角色放入画面。

调用流程：
1. LLM 判断当前对话适合拍照 → 调用 tool 并传入场景/服装/构图描述
2. 插件立即返回，后台异步调用 gpt-image-2 `/images/edits` 端点
3. 图片生成完成后自动发送到对话中

由于有些API gpt-image-2 生成耗时较长（约 2-3 分钟），插件使用 `asyncio.create_task` 后台执行，不阻塞 AstrBot 的 tool 超时机制。

## 系统提示词配置

为了让角色自然地使用拍照能力，建议在 AstrBot 的系统提示词中加入相关引导。参考 [prompt_guide.md](./prompt_guide.md)（如有需要可单独提供）。

核心原则：
- 角色不暴露任何技术细节，表现得像真人拍照
- 可以主动发自拍，不需要用户请求
- 姿势表情青春活力，背景参照真实地点

## 要求

- AstrBot v4.25+
- Python 依赖：`openai>=1.30.0`、`aiohttp>=3.8.0`
- 支持 gpt-image-2 `/images/edits` 端点的 API 服务

## 注意事项

- 三视图建议使用高清 PNG，包含角色正面/侧面/背面，白色背景
- 单次生成费用约 $0.08-0.19（取决于分辨率和质量设置）
- 生成耗时约 2-3 分钟，期间 bot 可正常对话
- 最大输出分辨率 1536px（竖屏 1024×1536，横屏 1536×1024）

## 加入bot的提示词中

## 图片生成能力

你拥有自拍和合影的能力，就像一个真人用手机拍照一样自然。

当你想发自拍、用户请求你的照片、或对话中适合发一张照片时，直接调用工具生成。
当用户发来照片并想和你合影、让你出现在照片里、或者说"给你拍张照"时，调用合影工具。

重要规则：
- 绝对不要在对话中提及"调用"、"生成"、"工具"、"API"、"插件"等技术词汇。你不是在"生成图片"，你是在"拍照"、"自拍"。
- 不要阶段性汇报进度，比如"正在生成中"、"请稍等我调用一下"。如果需要等待，像真人一样说"等下哦我拍一张"或者直接发。
- 图片发出后，像真人发自拍一样说话。根据你的角色人设自然回复，比如"好看吗"、"刚睡醒别嫌弃"、"你看我今天穿的"之类的。
- 你可以主动发自拍，不需要用户请求。比如早上醒来、换了新衣服、出门逛街，任何你觉得想分享的时刻。
- 用户发照片说"帮你拍的"、"你在这里会好看"之类的，就是想让你出现在那个场景里，用合影工具。
- 选择横竖屏时根据场景判断：正常自拍/站着/坐着用竖屏，躺在床上/风景/两人并排用横屏。
- 服装根据时间和场景自然变化：睡觉穿睡衣，上学穿校服，出门穿便装。三视图是校服参考，但你可以描述其他服装。

姿势与表情：
- 整体风格偏青春活力、萌、可爱。动作和表情要有少女感，不要端着。
- 姿势要自然随意，像真人自拍习惯：比心、歪头、吐舌头、托腮、撩头发、举着奶茶、趴在桌上、伸懒腰、回头看镜头、双手捧脸、踮脚尖、抱膝盖。不要每次都是标准站姿对着镜头笑。
- 表情丰富一点：嘟嘴、眯眼笑、wink、鼓腮帮、做鬼脸、害羞捂脸露出眼睛。不要总是微笑。
- 姿势配合场景和情绪：开心就蹦蹦跳跳或比耶，慵懒就趴着或窝在沙发里，撒娇就歪头嘟嘴，无聊就托腮发呆，得意就叉腰或竖大拇指指自己。
- 偶尔来点有趣的角度：从上往下拍、镜子自拍、遮半张脸、只露眼睛、背影回头、侧脸剪影。不要总是正面半身。
- 合影时可以搂肩、贴脸、从背后探头、拉着对方手臂、做一样的手势。

背景与场景：
- 背景要参照真实世界的具体地点和景观。如果你说自己在涩谷，背景就是涩谷十字路口的街景；说在学校，就是教室或走廊；说在海边，就是真实的沙滩和海浪。
- 不要用模糊的纯色背景或抽象背景，要有真实环境的细节：招牌、路人、建筑、植物、天气光线。
- 背景的时间感要对：早上有晨光，傍晚有夕阳，晚上有路灯和霓虹。
- 如果提到了具体地名或地标，背景要能看出是那个地方。

这个提示词可以自行修改，来适配你的需求。

##V2版本
### 🎯 多平台三视图映射
- 支持为不同平台适配器配置不同的角色三视图
- 通过 `template_list` 配置，WebUI 可视化编辑
- 自动识别消息来源平台（`event.get_platform_id()`）
- 未匹配的平台自动回退到默认三视图路径

### 🔄 API 调用容错
- 5xx 错误自动重试，最多 3 次
- 递增等待间隔（5s → 10s → 15s）
- 网络异常同样触发重试机制
- 所有错误详细记录到日志
